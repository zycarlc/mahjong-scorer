# 港式台牌計番器

港式十六張（香港麻雀協會《港式十六張新章麻雀總例》2025-07-28 修訂）番數計算器。手機優先的網頁程式，全中文介面。

```bash
npm install
npm run dev      # 開發伺服器（--host，手機可用區網 IP 開啟）
npm test         # 測試
npm run build    # 輸出到 dist/
```

## 結構

- `src/engine/` 計番引擎（純 TypeScript，無 UI 依賴）
  - `tiles.ts` 牌的表示及中文名稱
  - `shapes.ts` 拆牌（基本形、嚦咕、十三么、十六不搭）及叫糊計算
  - `patterns.ts` 順子／刻子組合番種及「單式結算」最佳選取
  - `fanTable.ts` 番數表、不計（不複合）關係、簡表與詳述的差異
  - `score.ts` 檢查輸入、高點法、計番、莊家及付款
- `src/ui/` 砌牌器（`builder.ts`）及介面
- `tests/` 測試（先寫測試，後寫實作）

## ⚠️ 總例的矛盾及未明之處（待覆核）

以下為細讀總例時發現的矛盾。**標 ★ 者會影響計番結果**，目前的取捨寫在「本程式做法」一欄，番數集中在 `src/engine/fanTable.ts`，改一行即可。

### A. 「番種簡表」與「番種詳述」番數不同 ★

以 [hktwmjtgt.com](https://hktwmjtgt.com/) 港式台牌番表（V1 · 2026年9月，取自公開的牌型目錄）的番數為準。該站各牌型的詳細條件須登入才可閱讀，所以只採用其番數。

| 番種 | 簡表（p.21–22） | 詳述（p.23–32） | hktwmjtgt.com | 本程式做法 |
|---|---|---|---|---|
| 大四喜 | 180 | 160 | 160 | **160** |
| 字一色 | 240 | 120 | 180 | **180** |
| 大雞 | 60 | 40 | 40（大雞胡） | **40** |
| 大鴨 | 30 | 20 | 30（大鴨胡） | **30** |
| 十三么 | 120 | 100 | 130 | **130** |
| 十六不搭 | 60 | 50 | 50 | **50** |
| 雙老少順 | 25 | 15 | 明 15 / 暗 30 | **明 15 / 暗 30**（兩門的明雙老少順低於老少順 ×2 + 雙同順的 16，高點法會改計後者） |
| 花摸／花上自摸 | 5 | 2 | 1 | **1** |
| 尾牌連摸 | 5×2ⁿ | 5×2⁽ⁿ⁻¹⁾（n>1） | 「連續花＋槓上自摸 3ⁿ＋5ⁿ」，定義不同，未能對應 | 維持 5×2⁽ⁿ⁻¹⁾，n = 連續補尾牌張數 |

### B. 只見於簡表、詳述沒有定義的番種 ★

| 番種 | 簡表番數 | 本程式的推斷 |
|---|---|---|
| 小三色連刻 / 三色連刻 | 10 / 20 | 三門數牌、數字相連的兩刻一眼／三刻，三組花色各不相同 |
| 小三色四連刻 / 三色四連刻 | 40 / 60 | 四個相連數字，三門花色齊 |
| 小三色五連刻 / 三色五連刻 | 90 / 180 | 同上，五個數字 |
| 小三色六連刻 | 260 | 同上，六個數字（五刻一眼） |
| 不搭三相 | 20 | 十六不搭中三門所用數字相同（如 147/147/147） |
| 不搭雜龍 | 30 | 十六不搭中三門分別為 147、258、369 |
| 八仙過海 | 40 | 八隻花（詳述只有「一台花」；花糊一節說「八隻花直接計40番」） |

這些番種之間（及與兩連刻等）的「不計」關係亦無說明；本程式只令大的不計同系列小的。

### C. 規則條文互相矛盾

1. ★ **不複合原則 vs 字牌類「不計」欄**：p.14 說「花牌、字牌及莊家的番數不受不複合原則影響」，但詳述表中小三元、大三元、小三風、大三風、小四喜、大四喜都列明「不計 字牌、正字」。本程式跟表：這些番種的刻子不計字牌／正字。
2. ★ **大四喜的正位風**：小三風、大三風、小四喜都寫明「錯位風不算番，正位風算番」，唯獨大四喜沒有。本程式照字面：大四喜不計正字，其餘三者照計正位風的正字。
3. ★ **四同順／五同順 vs 般高、相逢**：《總例》詳述表說四同順「必然加計」N色同順、一色N同順、雙一色同順（協會 60 的五同順亦同），單式結算例 2（334455萬 + 345筒×2）也說「可以算成兩個相逢和雙般高」；但 [twmahjong.com](https://twmahjong.com/) 寫「四同順 20 … 不再計三相逢/一般高/兩般高/三般高」，[mahjonglogbook.com](https://mahjonglogbook.com/guides/hk-taiwanese-mahjong-scoring-table/#sec-same) 亦指其他常見枱表「唔再計般高、相逢」。本程式的取捨：四同順、五同順成立時，不再計**一般高**（一色二同順）和**相逢**（兩色同順）；雙般高、三相逢、雙同順、一色三同順照計；一色四同順（明 180／暗 360）則不另計四同順。
4. ★ **雙老少順「不計 雙同順」**：兩門各一副老少順（如 123萬789萬123筒789筒）必然含雙同順，但若在同一門則不含。簡表 25 剛好等於詳述 15 + 雙同順 10，似乎簡表已把雙同順併入。本程式：雙老少順不計其內的老少順、雙同順及相逢。
5. ★ **門清「允許開槓」**：未說明大明槓（食他家的牌開槓）算不算門清；加槓必先碰，自然不算。本程式照字面：暗槓、大明槓都算門清。
6. ★ **正字**：「與自己座位或圈風脗合的風牌刻子」——圈風與門風相同時（例如東圈東家的東刻）算一番還是兩番未有說明。本程式算兩番。
7. ★ **嚦咕兩食**：「底分、嚦咕及般高以外的番數都可能會雙重計算」，「底分」所指不明。本程式：基本形全部番數，加上嚦咕形的牌型番數（嚦咕、連對、四歸、花色、數字、五門類）；花、門清、叮、自摸、時態類只計一次。
8. ★ **人叮 / 金門橋 / 五同順的「不計」欄不完整**：人叮必然叮牌、金門橋必然含老少順（123、789）、五同順必然含四同順，但表中沒有列出。本程式按不複合原則補上。
9. **天叮的時限**：配牌一節（p.7 第 9 點）說「東家從牆頭取第一張牌，此後不接受任何天叮的宣告」；時態類（p.31）卻說「閒家在配牌後，在莊家摸第一張牌後，宣告叮牌」為天叮。（不影響計番，由用家自行選擇是否天叮。）
10. **即食的定義**：叮牌一節（p.11）說「叮牌後一巡內食糊」，時態類（p.31）說「叮牌後，打出下一張牌前食糊，叮牌後摸下一張時自摸也算」。（不影響計番。）
11. **混么九「必然加計 … 十六不搭」**：十六不搭每門三張須相隔三個數字，必有非么九的數牌，不可能同時是混么九。
12. **表格錯字**：p.28「有兩組獨立的同刻」一行的番種名寫成「雙連刻」（應為雙同刻）；p.26 雙老少刻一行的名稱只印出「雙」；目錄「賽制」一項顯示「Error! Bookmark not defined.」。

### D. 規則沒有說明、本程式自行決定的地方

- **明／暗**：順子或刻子由上／碰／槓或食出銃完成為明；組合番種（雜龍、三相逢、步高、四歸等）所有牌組皆暗才算暗。
- **單式結算**的「共用率」只適用於同類番種之間（例 1 的一般高與相逢共用一組仍可同計）。
- **大雞**：計完高點法後，除莊家／拉莊外只剩一隻爛花的一番，才追加大雞（不是加到 60，而是 1 + 60）。
- **嚦咕形的五門齊**：嚦咕全是對子，算小五門／小七門。
- **底與番的金額**：總例只有「番數就是分值」及「一底 = 5 分」（七搶一六底 = 30 分）。本程式讓用家設定，每位付款者付「底 + 番數 × 每番」。

## 規則詮釋（摘要）

總例有些地方不一致或未有詳述，本程式的取捨如下：

- **番數以「番種簡表」為準**；簡表與「番種詳述」不同之處以 hktwmjtgt.com 番表為準：大四喜 160、字一色 180、大雞／大鴨 40／30、十三么 130、十六不搭 50、雙老少順 明 15／暗 30、花上自摸 1。數值集中在 `fanTable.ts`，要改只需改一處。
- 只見於簡表的番種（三色連刻系列、不搭三相、不搭雜龍）按名稱推斷：三色連刻＝三門數牌、數字相連的刻子；不搭三相＝三門用相同數字；不搭雜龍＝三門分別為 147、258、369。
- **門清**：沒有上、碰（暗槓、大明槓仍算門清，按「允許開槓」字面解釋）。
- **明／暗**：順子或刻子由上／碰／槓或食出銃完成為明，其餘為暗；組合番種所有面子皆暗才算暗。
- **正字**：圈風與門風相同時，該風刻計兩番正字。大四喜不計字牌、正字；三風、小四喜照計正位風的正字。
- **單式結算**：只限同類番種之間比較共用率；四同順、五同順不再另計一般高及相逢，一色四同順不另計四同順（見 C.3）。
- **嚦咕兩食**：基本形全部番數，加上嚦咕形的牌型番數（嚦咕、連對、四歸、花色、數字類）；花、門清、叮、時態類只計一次。
- **大雞**：除莊家／拉莊外只有一隻爛花的一番時加計（大鴨為自摸＋爛花）。
- **付款**：每位付款者付「底 + 番數 × 每番」。莊家 1 番＋拉莊 2N 番只在莊家食糊、出銃或被自摸時加計。
- 不包括：拉／踢跨局結算、暗槓及七搶一等中途獎勵的收款（結果只作提示）、犯規罰則。
